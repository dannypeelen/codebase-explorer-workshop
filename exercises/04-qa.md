# Exercise 4 — Gemini Codebase Q&A

**File**: `backend/exercises/qa.py` · **Tests**: `pytest backend/tests/test_qa.py -v`
**Time**: ~10 minutes · **Requires**: Exercises 1–3 done

## The concept

This is the exercise where it finally feels like "AI codebase explorer":
ask a free-text question, get a grounded answer with real citations.

The hard part isn't calling the LLM — that's one function call. The hard
part is **never trusting it blindly**. An LLM can cite a `node_id` that
was never in its context (plausible-sounding but unverifiable), or
fabricate a quote that sounds right but isn't actually in the source
text it claims to be from. Both are real failure modes for any RAG
system, not hypothetical ones — and the whole point of this exercise is
the validation step that catches them:

> A citation is kept **only if** its `node_id` is one Gemini was actually
> shown (from Exercise 3's `references`) **and** its `quote` is found,
> verbatim (whitespace/case-tolerant), in that exact item's text.

Anything that fails either check gets dropped, silently but *counted* —
`dropped_citations` in the response tells you how many, so a caller can
see "the model tried to cite something and it didn't check out" without
the UI ever showing a broken citation.

## What's already there

- `SYSTEM_INSTRUCTION` / `PROMPT_TEMPLATE` — the prompt. Already written
  to ask for exactly this: an answer, citations, and an
  `unable_to_answer` flag when the context doesn't support one.
- `Citation` / `AnsweredQuestion` — the Pydantic schema Gemini's response
  is forced into (`client.generate_structured` uses this for structured
  output, not free-text parsing).
- `quote_found_in_text` (`backend/validation.py`) — the whitespace/case-
  tolerant substring check. Already written; use it, don't reimplement it.

## What you implement

**`answer_question(question, client, query_vector=None)`**:

1. `client is None` → return a degraded response immediately (Gemini not
   configured; graph browsing/search still work).
2. Call `hybrid_retrieval.assemble_context(...)`. Empty context → a
   non-degraded "nothing relevant found" response.
3. Build the prompt (`PROMPT_TEMPLATE.format(...)`, with `context_items`
   JSON-encoded).
4. `client.generate_structured(prompt, AnsweredQuestion,
   system_instruction=SYSTEM_INSTRUCTION)`.
5. Validate every citation against `references` + `quote_found_in_text`
   as described above; keep the good ones, count the dropped ones.
6. Return the final dict (see the TODO docstring for the exact shape).

Wrap steps 2 and 4 so a `GeminiUnavailable` (bad key, quota, network)
degrades the response instead of raising — same rule as step 1.

The tests use a `FakeGeminiClient` (see `backend/tests/test_qa.py`) that

the validation logic without spending a real API call. For the real
thing, ask the UI's "Ask AI" panel something like:

> How does Flask's request context work?

and check that every citation it shows actually points at something real
— click one and confirm the quote is really in that file/PR.
